# Introduction

This document contains the requirements for the HelpCards project.

## Purpose

HelpCards is a .NET library for authoring help and knowledge content as Markdown cards with
YAML front matter, embedded in assemblies and served as command-line help for people and as
searchable knowledge for AI agents. These requirements cover the repository's current scope;
HelpCards-specific requirements will be added as its specification is finalized.

## Scope

This requirements document covers:

- Library API and functionality
- Self-validation framework
- Test result output formats
- Multi-platform support
- Documentation generation
- CI/CD integration

## Audience

This document is intended for:

- Software developers working on HelpCards
- Quality assurance teams validating requirements
- Project stakeholders reviewing project scope
- Users understanding the library's capabilities
