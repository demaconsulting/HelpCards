# Guide

How to set up and use the tool.
Also known as: start
Tags: tutorial, authoring

Start with `simple help guide setup` and then read `simple help guide usage`.
Run it with `--example run` or see `simple help guide --example settings` for the settings file.
The limits are described in `simple help reference limits`, and
the thing lives in another library.
A code span such as `[[x]]` is not a link.
Version 2.5 of simple accepts at most 42 items.

## Cards

- simple help guide setup
  Prepare the tool before the first run.
- simple help guide usage
  Everyday use of the tool.

## Examples

### run [command]

Run the tool on a file.

```shell
simple run input.txt
```

### settings [source] guide/settings.yaml

A settings file with the limit.

```yaml
---
limit: 42
mode: fast
```

### fragment [snippet] fragment.yaml

A fragment of a settings file.

```yaml
limit: 42
mode: fast
```

Print them in full with: simple help guide --examples, or one alone with:
  simple help guide --example <name>.
