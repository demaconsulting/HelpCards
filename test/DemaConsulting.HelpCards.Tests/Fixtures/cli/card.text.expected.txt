# Guide

How to set up and use the tool.
Also known as: start
Tags: tutorial, authoring

Start with `tool help guide setup` and then read `tool help guide usage`.
Run it with `--example run` or see `tool help guide --example settings` for the settings file.
The limits are described in `tool help reference limits`, and
the thing lives in another library.
A code span such as `[[x]]` is not a link.
Version 2.5 of simple accepts at most 42 items.

## Cards

- tool help guide setup
  Prepare the tool before the first run.
- tool help guide usage
  Everyday use of the tool.

## Examples

- run [command]: Run the tool on a file.
- settings [source] guide/settings.yaml: A settings file with the limit.
- fragment [snippet] fragment.yaml: A fragment of a settings file.

Print them in full with: tool help guide --examples, or one alone with: tool
  help guide --example <name>.
